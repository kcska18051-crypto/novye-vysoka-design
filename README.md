# Новые Высока — интерактивный дизайн

Отдельная публичная версия дизайна лендинга «Новые Высока». Исходный прототип сохранён отдельно и остаётся доступным для сравнения.

- Дизайн: https://kcska18051-crypto.github.io/novye-vysoka-design/
- Исходный прототип: https://kcska18051-crypto.github.io/novye-vysoka/
- Репозиторий дизайна: https://github.com/kcska18051-crypto/novye-vysoka-design

Для продолжения на другом компьютере начните с `PROJECT-CONTEXT.md` и `docs/visual-design-handoff-2026-09-24.md`. Правила работы для Codex находятся в `AGENTS.md`.

## Текущий статус

Реализованы видео первого экрана, белая визуальная основа, карточки УТП, панорама территории и крупная анимированная фотопрогулка. Исходные PNG визуализаций сохранены в `source-assets/lifestyle/`, оптимизированные файлы сайта — в `dist/`.

Добавлена единая интерактивная карта кварталов и окружения: пять сменных генпланов, карточки инфраструктуры, фильтры, показатели кварталов и мобильная нижняя карточка. До получения данных клиента значения цены и наличия помечены «Уточняется».

Для обновления квартала достаточно заменить соответствующий файл `dist/assets/quarters/quarter-N.webp`. Исходный PDF и сценарий нарезки сохранены в `source-assets/masterplan/` и `tools/export-quarter-plans.py`.

## Медиа первого экрана

Использован предоставленный полный горизонтальный ролик: https://disk.yandex.ru/i/ND0oClaIwwDG2g . Это монтаж предоставленной съёмки, не ИИ-генерация. Продолжительность около 11,5 секунды. Есть отдельные desktop/mobile версии и постеры; при reduced-motion, save-data или 2G остаётся статичное изображение.
