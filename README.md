## Локальный просмотр

Требуется Node.js. Запустите из этой папки:

```sh
node server.cjs
```

Откройте http://127.0.0.1:4174/ . Остановка — Ctrl+C.

Файлы сайта находятся в `dist`. Сервер доступен только на этом компьютере. Формы демонстрационные, реальные заявки не отправляются. Схема и участки сохраняют существующую маркировку условных данных.

## Ветки

- `codex/design` — исходники сайта, сервер и этот README.
- `codex/pages` — содержимое `dist` в корне; GitHub Pages публикуется из этой ветки.

Обновление публикации после отдельно согласованных правок:

```sh
git subtree split --prefix dist -b codex/pages
git push origin codex/design codex/pages
```

При повторном обновлении используйте временную ветку для `subtree split` и обычное fast-forward обновление `codex/pages`; не перезаписывайте историю принудительно.

Архивы чатов и аналитические документы в эту копию не перенесены. Прототип не удалять без отдельного решения пользователя.
