# Новые Высока — интерактивный дизайн

Первый этап: полноэкранный видеофон, текстовая группа слева и молочная полоса с тремя линейными иконками. Остальные блоки и интерактивный генплан сохранены из прототипа без изменений.

- Дизайн: https://kcska18051-crypto.github.io/novye-vysoka-design/
- Исходный прототип: https://kcska18051-crypto.github.io/novye-vysoka/
- Репозиторий: https://github.com/kcska18051-crypto/novye-vysoka-design

База: `novye-vysoka`, ветка `codex/prototype`, коммит `c619f35c471b2ded95d164f3145f9be4770692de`.

## Медиа первого экрана

Использован предоставленный полный горизонтальный ролик: https://disk.yandex.ru/i/ND0oClaIwwDG2g . Это монтаж предоставленной съёмки, не ИИ-генерация. Взяты чистые фрагменты 72,96–75,20; 75,32–77,56; 77,68–79,92 секунды. Скорость уменьшена вдвое, добавлены мягкие переходы по 0,6 секунды, в том числе на стыке петли. Звук, титры и метаданные исходника удалены.

- Продолжительность: 11,5 секунды, H.264, 24 кадра/с, faststart.
- Десктоп: 1280×720, 2 927 489 байт (2,93 МБ).
- Мобильный: 540×960, около 1,22 МБ, отдельное вертикальное кадрирование.
- Постеры: 1280×720 / 540×960; около 183 / 74 КБ.

Браузер выбирает один видеофайл по ширине экрана при загрузке. Постер загружается сразу, видео — после загрузки страницы. При reduced-motion, save-data или соединении 2G видео не запрашивается. Если автозапуск запрещён, остаётся постер и кнопка включения. Есть доступная пауза, остановка в скрытой вкладке и мягкое появление полосы преимуществ с учётом reduced-motion.

## Просмотр и публикация

`node server.cjs` → http://127.0.0.1:4174/

`codex/design` содержит исходники, сервер и README. `codex/pages` содержит только `dist` в корне и публикуется GitHub Pages. Для обновления: коммит исходников, `git subtree split --prefix dist` во временную ветку, обычное fast-forward обновление `codex/pages`, push обеих веток. Не использовать принудительную перезапись истории.

Формы демонстрационные, данные не отправляются. Условный генплан сохраняет исходную маркировку. Чаты и аналитические документы не публикуются. Прототип не изменять и не удалять без отдельного указания.
