# Состояние подтверждённой заявки

Подготовлено 16.10.2026. Backend пока не подключён; демонстрационная отправка не показывает подтверждение получения заявки.

После подтверждённого успешного ответа сервера контроллер отправки вызывает на соответствующей форме:

```js
form.dispatchEvent(new CustomEvent('lead:success'));
```

Событие заменяет поля и кнопку формы на «Спасибо! Ваша заявка принята» / «В ближайшее время с вами свяжется менеджер.». Дополнительных кнопок нет. У модального окна остаётся существующее закрытие крестиком и Escape. При повторном открытии модальной формы восстанавливаются поля и кнопка.

Событие — только интерфейс отображения успешного результата, оно не отправляет данные и само не доказывает получение заявки. Backend-разработчику нужно заменить демонстрационный обработчик submit в `dist/app.js`, подключить отправку FormData, обработку ошибок и серверную защиту повторных запросов. Сценарий обращения хранится в `intent` / `popup-intent`, выбранный квартал — в `quarter`. При ошибке сервера событие `lead:success` вызывать нельзя.

Клиентская валидация телефона и согласий должна сохраняться. Перед запуском нужно заменить ссылки-заглушки пользовательского соглашения действительным документом клиента.
